PCに同時接続された**ゲームコントローラー、キーボード、左手デバイス（Razer Tartarus等）、テンキー、マウス、VR機器、フットペダル、Bluetooth機器**の入力信号をリアルタイムに識別・視覚化し、**Windows OSレベルでの物理無効化/完全停止および個別ON/OFF切り替え**を行えるゲーマー・クリエイター向け超軽量デスクトップアプリケーションです。

---

## ✨ 主な特徴

- 🚀 **単一ネイティブ実行ファイル (`InputNexus.exe`)**:
  - コマンドプロンプト等の黒い画面を一切出さず、ダブルクリック一発で独立ウィンドウとして超高速起動（ファイル容量わずか5KBの極小設計）。
- 🎨 **サイバー・ベクターシルエット自動描画 (SVG)**:
  - 接続された機器（ゲーミングマウス、左手デバイス、ゲームパッド、テンキー、キーボード）に応じて、ネオン調のベクターシルエットが自動で美しく発光。
- 🔊 **SFサイバーパンク効果音シンセサイザー (消音機能付き)**:
  - Web Audio APIによるリアルタイムシンセシス（外部音声ファイル0Byte）。デバイスON/OFF時のメカニカルなラッチ音や、一発で消音できる `🔊 効果音: ON/OFF` トグルを搭載。
- ⚡ **リアルタイム発光アクティビティパルス**:
  - キー押下、ボタン操作、スティック傾き、マウス移動に反応して該当カードがネオン発光。
- 🛡️ **Windows OS PnP デバイス物理停止**:
  - アプリ内のON/OFFスイッチ切り替えにより、特定のマウスやキーボードをWindowsレベルで物理切断（カーソル不動・ボタン全無効化）。
  - **誤無効化防止保護**: 動作中の最後の1台のマウスを誤って切断しないセーフティ確認ダイアログ機能。
- 🚨 **緊急一括復旧ショートカット (`Ctrl + Alt + Shift + R`)**:
  - 万が一の操作不可時やPCフリーズ時でも、キーボードショートカット一発ですべての機器の無効化を即座に解除・一括ONリセット。
- ⚙️ **キー干渉防止・ショートカット自由カスタマイズ**:
  - 他のゲームや通話ソフト（Discord、OBS等）とショートカットが被らないよう、ミニHUDの呼び出しキーを自由に変更または無効化可能。
- ✏️ **機器の自由なニックネーム（命名）保存**:
  - ✏️ アイコンを押すことで、「IBMテンキー」「メインキーボード」「左手Tartarus」など好きな名前に命名・保存可能。
- 🛒 **スマート・レコメンド（関連アクセサリ案内）**:
  - 認識されたブランドや機種（Logicoolソール、Tartarusリストレスト等）に応じたおすすめ関連品リンクをスマートに表示。
- 🎮 **フルスクリーンゲーム対応「ミニHUDモード」**:
  - 画面隅に常駐する超小型オーバーレイへ即座に切替。ゲーム画面を妨げずに素早くON/OFF。
- 🚀 **CPU負荷 0.0% 超軽量動作**:
  - ゲームのフレームレート（FPS）低下や入力遅延（インプットラグ）を一切起こさないハードウェアアクセラレーション設計。

## 🚀 使い方・起動方法

### 1. `InputNexus.exe` をダブルクリック（推奨）
フォルダ内の `InputNexus.exe` を実行するだけで、タブやアドレスバーのない独立した専用アプリ画面として起動します。

### 2. インストーラーによるショートカット作成 (`Install-InputNexus.ps1`)
`Install-InputNexus.ps1` を右クリックして「PowerShell で実行」を選択すると、デスクトップおよびスタートメニューに専用ショートカットアイコンが自動作成されます。

## 📤 他ユーザーへの配布方法

[GitHub Releases](https://github.com/yukiyanA-Git/device-controller-app/releases) から最新の `InputNexus_Package.zip` をダウンロード・解凍するだけで、どのWindows PCでもインストール不要・即座にご利用いただけます。

ローカル初回起動時に `scan_devices.ps1` が自動実行され、お使いのPC環境のPnPデバイスデータが即座に生成・反映されます。
